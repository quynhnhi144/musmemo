MusMemo

A private, single-user workout scheduler.

Every evening MusMemo picks one workout from a personal YouTube playlist and puts it on the owner's Google Calendar for the next morning, together with the weights to use. It learns from the days that get skipped and eases the load so the habit survives.

It is a personal project with exactly one user — its author. It is not a product, it is not for sale, and it does not accept sign-ups.
