Privacy Policy

MusMemo · last updated 26 September 2026

MusMemo is a personal project with a single user, its author. There are no other users, no accounts and no sign-up. This policy describes what the software does with that one person's data.

What it accesses

  • Google Calendar (calendar.events) — creates one event each morning and reads that event back to see whether the workout happened. It does not read unrelated events.
  • Gmail (gmail.send) — sends a weekly summary to the owner's own address. It never reads mail.
  • YouTube Data API — reads public metadata (title, channel, duration) for videos in the owner's playlist. No video is ever downloaded.

What it stores, and where

A single SQLite file in a private GitHub repository: workout history, weights lifted, and the tags attached to each playlist video. Nothing else.

What it shares

Nothing with anybody. Video titles and channel names are sent to the Anthropic API to be classified by muscle group and intensity; no personal or health data is included in those requests. There is no analytics, no advertising, and no third party with access to the data.

Google user data

MusMemo's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never used for advertising, never sold, and never transferred to anyone.

Retention and deletion

Data lives until the owner deletes it, by deleting the repository. Access can be withdrawn at any time at myaccount.google.com/permissions, which immediately stops all access.
